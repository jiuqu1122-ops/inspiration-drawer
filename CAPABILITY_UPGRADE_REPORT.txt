1. 架构变化
- 沿用 AI CENTER 的模型目录、能力 JSON、价格版本和路由，新增字段经后端公共目录及 Rust 桥接传到客户端。
- 图片质量下拉框由 supportedQualities 驱动。没有配置时隐藏；请求只按配置的 qualityParameter 发送质量值。
- 通用图片适配器按 outputMode/maxOutputImages 保留多资产。一轮请求返回的所有配置范围内图片均进入保存和展示流程，工作流结果也保留额外资产。
- billingMode 控制按请求或按图片计费。质量价格优先匹配，未配置对应质量时沿用旧分辨率/基础价格。
- 新增独立 music-service/music-adapter、audio 模型类型和 music_flat 计费。发送一次 POST，解析所有 choices 的音频链接，保存全部音频资产。
- 音乐请求复用 clientRequestId 保证重复请求不重复扣费。超时、连接失败和 5xx 不重发，保留预扣等待确认；明确拒绝时释放预扣。
- 音乐节点使用与其它入口一致的 SVG 图标，位于视频入口下方；复用模型选择器，提供提示词、生成状态、音频试听与下载，并适配深色模式和节点缩放。assetType 标识音频，音乐输出可作为视频参考。
- 音频流式下载到临时文件，经现有存储抽象上传到 COS 的 generated-audios 命名空间；持久化 objectKey 和稳定 API 地址，每次播放/视频引用重新签名。下载单独签名为附件，支持多格式。
- 上游成功结果先保存为请求回执，再逐个转存。COS 故障可用同一请求 ID 或认证 GET 恢复，保留原价格快照；客户端的「恢复结果」不再 POST，原生传输也禁止音乐 POST 连接失败自动回退。
- 上传图片的删除/替换等修改意图进入编辑工具。通用适配器由 supportsImageEdit 决定编辑接口或带参考图的生成接口，不回退为纯文本。
- 复制媒体节点沿用资产 ID、缓存路径和缩略图，画布节点 ID 重新生成；一同复制的引用节点重新映射，无需重新下载媒体。
- 工作流会话按 canvasId + nodeId 绑定。聊天消息沿用现有 SQLite 持久化；会话绑定和结果卡存入本地持久化存储，重新进入画布可恢复。
- 缩放会重设当前拖动基准，拖动前提交未完成缩放，避免旧滚动偏移覆盖新视口。
- 画布列表支持长按 350ms 后拖动排序，完整顺序通过 SQLite 事务保存。
- Shift 先选参考节点，再选 AI 节点可连接；对话列表支持 Shift 区间多选、确认删除、保留运行中/删除失败的会话并刷新状态。

2. 数据结构变化
能力 JSON 新增：
  supportedQualities: string[]
  qualityParameter: string（默认 quality）
  outputMode: single_asset | multiple_assets
  maxOutputImages: number（1..16）
  billingMode: per_request | per_image
  supportsImageEdit: boolean
请求：ImageInput/原生桥接增加 quality?: string。
售价：creditsPerImageByResolutionQuality[resolution][quality]。
公共价格投影：creditsByResolutionQuality[resolution][quality]。
成本：cnyPerImageByResolutionQuality 或 amountPerImageByResolutionQuality；保留原币种。
图片结果：兼容 images[]，新增 imageAssets[{assetType:"image",url}]。
音乐结果：{type:"audio",content:"",audioUrls:[],assets:[{assetType:"audio",url,objectKey,mime,size,name}]}。
音乐请求恢复字段：CanvasAiItemData.musicClientRequestId；服务端 AiRequest.result 暂存 music_storage_pending 回执。
新增访问接口：GET /v1/ai/audio-results/:key（播放/引用，download=1 下载）；认证 GET /v1/ai/music/generations/by-request/:requestId。
节点及工作流结果：assetType?: image | video | audio；工作流端口支持 audio/audio[]。
计费：新增 music_flat；快照保存 quality、billingMode 和预估结果数量。
数据库：AiCapability 增加 AUDIO，迁移文件为 20261014120000_add_audio_capability/migration.sql。
画布排序继续使用已有 sort_order 列；工作流绑定使用版本化本地存储键。

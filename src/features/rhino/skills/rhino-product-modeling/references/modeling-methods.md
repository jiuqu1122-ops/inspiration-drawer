# 建模方法选择与返修

用于选路线、建立输入约束及定位失败原因。所有命令和参数均先按实际 Rhino 版本及可用接口核对，不将本文命令清单当作环境已具备的能力。

## 常见几何路线

| 几何条件 | 优先考虑 | 典型产品或部件 |
| --- | --- | --- |
| 等截面、平面和规则结构 | ExtrudeCrv、布尔运算、阵列 | 框架、支架、面板 |
| 绕轴变化的形体 | Revolve，配合截面与轴线检查 | 瓶体、旋钮、轮毂 |
| 由纵向截面或导轨控制 | Loft、Sweep1、Sweep2 | 把手、握把、壳体 |
| 多方向造型和较高反射要求 | EdgeSrf、NetworkSrf、MatchSrf、BlendSrf | 家电外壳、汽车覆盖件 |
| 有机形态和早期形体推敲 | SubD，保留控制笼 | 鼠标、座椅、软包 |
| 尺寸变化、重复或系列结构 | Grasshopper，定义参数边界并复查输出 | 格栅、孔阵列、系列家具 |

选择依据是形体与编辑目标，不是产品类别名称。规则结构没有必要为了“高级曲面”改成复杂网络；探索阶段的 SubD 也不能因外观顺滑就免于后续验收。

## 曲面命令的输入与检查

| 输入与目标 | 候选方法 | 操作前检查 | 操作后检查 |
| --- | --- | --- | --- |
| 单方向的一系列主截面 | Loft | 截面方向、顺序、闭合缝一致；截面数量足以表达形体 | 截面间鼓包、端部、轮廓 |
| 单轨带截面或局部条带 | Sweep1 | 轨道连续性、截面定向与比例 | 截面旋转、扭曲、接缝 |
| 两条明显边界配合横截面 | Sweep2 | 两轨结构兼容，截面端点落轨，排序正确 | 两轨间扭曲、端部、截面保持 |
| 清晰的四边底层区域 | EdgeSrf 后调点或接面 | 边界方向与连接关系清楚；不假设自动相切 | 内部形状、邻面连续性 |
| 两族曲线共同定义曲面 | NetworkSrf | 同族不相交，与另一族按网络要求相交，偏差可接受 | 拟合偏差、复杂度、过拟合 |
| 已有边较接近且需匹配 | MatchSrf | 修改侧为未修剪边，明确固定侧和对端约束 | 所有邻边、目标轮廓、新增节点 |
| 两边之间有过渡宽度 | BlendSrf | 方向、边链、连续性目标、过渡空间 | 鼓起、下陷、扭曲、自交 |
| 早期自由形态探索 | SubD | 对称、控制笼、特征走向 | 比例、反射；转 NURBS 后另行验收 |

### 不可忽略的条件

- Sweep2 的边缘连续性选项受输入结构限制。原文指出轨道需为曲面边，截面需满足非有理等条件；以当前版本实际可选项及官方命令说明为准，不将表格视为完整参数规范。
- NetworkSrf 不能修复互相矛盾的网络，不能靠放宽拟合容差掩盖输入问题。刻意硬折线应明确建模，不假定网络自动保留。
- EdgeSrf 可使用 2 至 4 条边界；三边闭合输入可能形成奇异点，在外观光顺区谨慎使用。边界闭合和相邻面相切是不同问题。
- MatchSrf 前保护母面，明确修改侧与固定侧。修改一边后复查其他连接边，不连续盲配；不要为可选边而随意 Untrim 成品。
- 曲线升阶不自动消除形状缺陷；Rebuild 或简化后须量测相对原始目标的偏差。
- 保留 SubD 控制笼和 Grasshopper 定义；任何转换、烘焙或导出后的对象都要重新检查，不继承转换前的全部结论。

## 失败定位与返修

| 现象 | 优先调查 | 修正与复查 |
| --- | --- | --- |
| 主面波浪或局部鼓包 | 输入曲线波动、截面过多、控制点分布不均 | 简化并量测偏差，重新建面；复查截面与轮廓 |
| 扫掠扭转 | 截面方向或闭合缝、排序、两轨对应关系 | 统一方向和对应关系，先以少量截面验证 |
| 接好一边后另一边破坏 | 约束冲突、结构不足、修改范围过大 | 保护邻边，重构局部或调整拆面，再检查全部邻边 |
| 接上但反射折断 | 仅 G0、相切或曲率不符，或显示网格不足 | 排除显示误差后检查连续性，再决定匹配或重建 |
| MatchSrf 无法选边 | 修改侧为修剪边或边链对应错误 | 在副本上重建合适母面或边界，不随意取消修剪 |
| BlendSrf 下陷或鼓起 | 过渡空间不足、手柄长度、相邻面形状 | 扩大合理过渡区，调整边界或截面，复查自交 |
| 偏移或倒角失败 | 半径超出局部可用空间、碎边、自交 | 先修主形，再调整局部构造或手工建立过渡 |
| 渲染裂缝但几何接近 | 网格不一致或真实缝隙 | 数值查边，调整网格或合理 Join，不用 JoinEdge 遮盖 |
| 导出丢部件或尺度错误 | 选择集、隐藏层、单位、格式设置 | 独立文档回读，逐部件和标尺核对 |

一次返修形成闭环：记录问题对象和证据，定位上游原因，保存恢复点，修改，再复查受影响的形体、接缝、厚度与文件。旧证据若不再对应当前几何，标记失效或生成新证据。

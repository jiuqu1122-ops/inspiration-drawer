# 验收规程与证据要求

在定义指标、阶段检查和最终报告时使用。按约定用途选择适用项目，不把外观学习标准扩展为装配、运动、打印或制造合格结论。

## 1 先定义标准

每项至少记录：指标名称、对象范围、目标阈值及单位、工具与方法、标准来源、是否暂定、是否关键。优先采用用户、项目或下游明确要求。

以下数值继承自原文，只是外观学习或展示阶段的起始建议，不是已验证项目数据，不是汽车行业 A 面标准。采用前结合尺度和用途确认，禁止静默作为生产公差。

| 项目 | 起始建议或制定方式 |
| --- | --- |
| 单位 | 可使用毫米；已有模型优先核对实际单位与尺度，不未经确认转换 |
| 文档绝对公差与角度公差 | 可暂用 0.01 mm 与 0.1°，按尺度调整；设置值不等于实测误差 |
| 已知尺寸 | 逐项规定允许误差；无其他要求的概念体块可暂用目标尺寸的 0.1%，下限为 0.1 mm，并标为概念阶段标准 |
| 参考轮廓 | 校准后的同视角叠图；数值检查要明确标定条件、像素或长度误差；未标定仅作视觉检查 |
| 预期连接边的位置差 | 可暂以 0.01 mm 为目标，须实际测量；记录工具是否采样近似 |
| 指定 G1 接缝 | 定义角度指标和计算口径；可暂以 0.1° 为相切角度目标，不能用文档设置代替测量 |
| 指定 G2 接缝 | 定义曲率指标、单位或归一化口径、适用区间和支持工具；缺少这些条件时，数值项为未验证 |
| 对称 | 检查声明的对称范围；严格镜像副本与镜像结果对照，记录刻意非对称豁免 |
| 部件间隙与厚度 | 使用任务或设计值；无数据的概念值须标明假设，不能据此宣称可制造 |

文档角度公差、MatchSrf 面板参数和实际测量结果是不同数据。近零曲率处相对误差会不稳定，要记录工具定义、适用区间及必要的绝对曲率判据；不能虚构适用于所有接缝的“统一 G2 百分比”。

## 2 三类证据分别保留

| 证据类别 | 主要检查 | 不能替代的证据 |
| --- | --- | --- |
| 外形符合性 | 多视图或透视对照、关键尺寸、轮廓及截面对比 | 接缝数值质量、几何和文件有效性 |
| 曲面质量 | 数值接缝检查、双方向斑马纹、多视角 EMap 或反射、必要的曲率分析 | 比例、尺寸、可编辑性与文件可用性 |
| 几何与文件 | 坏对象、意外裸边或非流形边、实体有效性、重开与导出回读 | 造型正确和视觉反射质量 |

斑马纹是视觉线索，不是全边数值证明。图片不证明模型可编辑；程序无报错也不证明形状正确。若测量仅覆盖采样点，写明采样位置、数量、工具设置和未覆盖区域，不将采样结论写成完整数学保证。

## 3 执行检查

### 外形与输入

- 核对总包络、主要基准、关键尺寸、部件位置与任务指定轮廓。汽车补充轴距、轮距、轮胎、接地和前后悬；其他产品替换为对应字段。
- 曲线检查方向、端点和 CurvatureGraph。简化或 Rebuild 后比较与原始目标的偏差，不仅观察更少控制点。
- 参考图有透视、遮挡或标定不足时，在结果和证据中明确局限。

### 几何与边界

- 使用当前版本实际可用的 Check、SelBadObjects 等工具检查，保留对象 ID 与错误记录；参数按实际命令文档核对。
- 用 ShowEdges 或可用方法检查裸边与非流形边。列出设计允许的开口与意外缺陷，不将所有开口误判为错误，也不将要求闭合的壳体开口豁免。
- 预期实体检查有效性、闭合与必要的厚度、自交；布尔、偏移和窄过渡后重点复查。

### 连续性与反射

- 对需要连接的边分别检查位置、相切或曲率要求；真实分件缝和硬折线按设计意图检查。
- 原文提及 Rhino 9 的 GlobalEdgeContinuity。仅在实际版本和接口支持时使用；否则找当前可用接缝工具，或标记数值项未验证。
- 不将 GCon 的曲线端点检查写成整个曲面接缝的证明。命令可用性与证明范围分别记录。
- 斑马纹至少覆盖水平、垂直两个方向以及整体和问题局部；多视角检查面内波动和跨缝反射，记录分析网格设置。
- 数值与视觉结果冲突时调查显示网格、采样与几何原因，不任选一个掩盖另一个。

### 部件 装配与文件

- 按范围检查静态穿插和间隙；厚度或运动要求使用实际工艺和姿态条件。没有运动验证时不宣称动态无干涉。
- 隐藏或显示主要图层，确认部件可独立选择；必要时在副本上移动并撤销，以验证独立性，不破坏原件。
- 最终保存后重开原生文件；约定的导出文件在独立文档回读。核对单位、范围、关键尺寸、部件与闭合状态，解释转换导致的数量或组织变化。

## 4 状态与总体结论

| 状态 | 使用条件 |
| --- | --- |
| 通过 | 有对应当前几何的证据，且满足已声明标准 |
| 未通过 | 实测或观察不满足标准，记录对象、问题、影响和修正建议 |
| 未验证 | 缺工具、缺数据、未执行或无法证明；不能写为通过 |
| 不适用 | 在约定范围外或结构上无此要求，记录具体理由 |

将影响外形、关键连接、几何有效性及文件可用性的适用项目设为关键项。关键项有未通过或未验证时，不给“整体验收通过”；可以报告阶段完成并交付待办。

“仅完成视觉检查”与“数值连续性通过”是不同结论。若文件未重开、导出未回读或脚本未执行，应分别说明，不用“全部正常”概括。

## 5 证据与返修记录

证据按阶段、对象和内容命名，例如 S04_housing_P12_zebra_horizontal.png、S07_edge_P12-P13_measurement.csv。截图标明视角、对象和相关设置；数值记录保留单位、工具、阈值、测量口径及采样局限。

报告只链接实际存在的文件。缺证据时写“未生成”并标为未验证，不制造空链接。返修后复查所有受影响项，并保留当前模型与证据的版本对应关系。

需出具报告时使用 [验收模板](../assets/acceptance-report-template.md)。模板里的“未设定”“未检查”“未生成”是待记录字段，不是已发生结果；依据当前项目替换后再出具结论。

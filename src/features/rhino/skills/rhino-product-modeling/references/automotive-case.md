# 汽车及类似复杂外壳案例

这是通用流程的专项示例，不是汽车生产级 A 面认证规程，也不要求其他产品具有轮拱、轴距等字段。应用到家电、消费电子等产品时，将其替换为实际基准、关键尺寸和部件。

## 引擎盖 车顶与翼子板

先控制主拱度、肩部体量及纵横截面，尽量保留较大母面；基础连接稳定后再做零件缝与小特征。轮拱是开口轮廓，不应成为决定全部翼子板体量的唯一输入。

有扫描时在多个截面与参考比对；无扫描时用可靠的多视图和照片交叉检查。照片复刻与扫描拟合的数据精度条件不同，不能套用同一证据结论。

## 车侧与特征线

先判断腰线是折线、窄过渡还是反射效果。光顺设计采用合适面间过渡，硬折线建立明确边界；不要因照片上出现一条高光就切出沟槽。

车门等真实分件缝可在形体稳定的母面上分割，分割前保留母面副本。实物分件不要求跨零件消除真实间隙。

## 保险杠 进气口与多面转角

先建立外包络和上下体量，再切分格栅及进气口，并为大过渡留空间。避免多条狭窄曲面同时挤入一个点。

多边洞优先考虑重新规划四边底层面并修剪；受控补面只用于适合的局部，不能以通用补洞替代整块主面规划。

## 后视镜 灯具与玻璃

后视镜分为壳体主形、底部与支架，先检查壳体反射再开结构缝。灯具区分外罩与内部结构；玻璃区分表面连续外观和真实密封边界。缺少厚度、安装空间和密封数据时，标为概念假设，不宣称可制造。

## 对称中缝

将中心边置于对称平面，检查横穿中缝的切向、相关控制点行和曲率，满足项目所需的镜像光顺条件。镜像后跨缝观察反射，并量测要求的连续性。

中心边重合只解决位置问题，不证明 G1 或 G2。设计非对称区域单独记录并从镜像检查范围中排除。

## 汽车项目的比例检查字段

按任务记录轴距、轮距、总长宽高、轮胎尺寸、接地及前后悬。未知字段标为缺数据或概念假设，不从单张透视图虚构精确尺寸。对其他产品改用其总包络、功能位置、握持或安装基准、开口和配合尺寸。

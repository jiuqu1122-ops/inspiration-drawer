## 查明并修正

1. hasRhinoNativeWriteTools 之前依赖已知 build/connect/solve/write 分类，像 set_camera、manage_plugin_commands 等未分类能力会被错误忽略；改为根据声明的 readOnly 元数据判断，不把阶段提示当能力白名单。
2. 原生名称以 rhino_ 开头、含点或过长时可能被过滤／不符合模型函数名限制；新增稳定映射和 rawName 回传，避免本地 helper 名冲突，并去重。内部 _router_ 工具仍不向模型公开。
3. 非出图任务的可选视口和分件读取失败曾先于 MCP 调用中止整轮。现在对查询、材质、相机、文件等任务降级为缺少可选上下文；真实出图所需的参考图/Mask 仍失败关闭。
4. 文档切换定时器以前可在原生调用期间再次 MCPStart。启动／重绑定现与 resolve+call 共用同一信号量，关闭时抑制排队的启动；多文档指纹校验仍保留。
5. 图像回执以前仅识别特定视口工具名。现在通用原生图像块可成为有大小上限的下一轮视觉观察，不把 base64 永久写入工具历史。
6. 显式 readOnlyHint=false 不再被名字像读取工具的分类覆盖，从而避免把潜在副作用错误当成可自动重试的只读操作。

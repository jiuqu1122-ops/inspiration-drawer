# Chat / Rhino 五项问题修正（2026-11-18）

## 1. Figma / Sketch 能力识别

- 原型工具不再只由少数词命中后才对模型可见；非 PPT 回合提供真实的 create_ui_prototype 能力供模型结合语义选择。
- 每轮显式告知实际交付格式为 .sketch，而非 .fig；不能因没有原生 .fig 能力而否定整项可编辑设计需求。不生成改后缀的假 .fig，不声称访问了 Figma 账户。
- 明确请求文件但模型未调用工具时，仅续接一次原型交付；仍不调用则如实报错，不无限尝试或伪造下载链接。
- 方法咨询、提示词讨论及明确拒绝 Sketch 替代的请求不触发交付续接。真实工具权限、参数校验和文件回执仍是执行边界。
- 自动测试的 provider 回复是合成数据，没有调用付费模型。不能据此证明任意上游渠道都支持工具调用；截图里的上游协议/工具透传仍需实际渠道验收。

## 2. 参考图建模错误

- 本地预检识别已知 RhinoObject/BrepObject 接收者上错误的 SetMeshParameters，提示真实的 SetRenderMeshParameters，在远程执行任何脚本前允许一次有边界的修正。
- 对已知解析实体和字面量非均匀缩放补充预检，对零缩放拒绝派发；未知动态类型不猜测、不擅自改写执行代码。
- 工作流指令要求私有副本、MakeDeformable 成功检查、Transform 与有效性日志、实体朝向/体积/边界检查；全部部件在内存校验后才写入。不能跳过失败部件或把单个成功操作当成完整建模成功。
- 远端失败不证明零副作用，仍禁止盲目重放；已完成对象保留。截图中的原始脚本和原参考图文件未提供，未在 Rhino GUI 中复现那两条原始建模请求，不能宣称任意参考图建模都已通过。

## 3. Rhino 本地图片

- 面板新增本地图片按钮、缩略图和移除。支持 PNG/JPG/WebP/BMP，前端缩放/压缩为有界 PNG/JPEG；仍可同时选择画布参考图。
- 本地图片通过已认证的同文档命令传递，桌面使用受控文件名保存，再进入原有视觉附件路径。数量、格式、大小双端验证；视口/Mask 有附件预留时明确报错，不静默丢本地图。
- 命令回执和面板轮询不回传原图 base64；接受后释放队列中的原图，通过内容散列保留幂等性，防止同 ID 换图及重复写入。
- Rhino 8 / 9 资源均重新构建并同步到 src-tauri/resources/rhino。没有替换用户已安装的运行中插件。

## 4. 快捷键

- 串行化旧 effect 清理、新注册，避免异步旧清理注销新键。
- 录制期间暂停本应用全局键注册，并避免画布捕获录制键。物理键码处理 Shift 标点、非英文键盘布局和功能键；忽略 IME/长按，Esc 取消。
- 后端先验证合法键、应用内重复和 OS 可注册性，再保存。保存失败显示错误并保留原配置，不先更新 UI 假装成功。
- 自动测试覆盖实际 effect 注册/清理交错；未在用户的其他机器上验证第三方软件占键情形。

## 5. 长文本输入框

- 桌面 Chat 依据内容自动增高，超出视口相关上限后滚动，清空/缩短后收回；宽度及窗口变化重新计算，不重建 textarea、不改动 IME 和发送行为。
- Rhino 面板同步支持输入框自适应。
- 隔离的原生 WebView2 真实 ChatView 回归：1240 与 420 逻辑像素宽度均通过，文本框由 46px 扩大到约 311.6px，缩短后回到 46px。
- 截图和 JSON：outputs/html-preview-verification/native-{1240,420}.{png,json}。探针不加载用户数据库、不发送模型请求、不执行建模。

- 生图模型、比例、清晰度、质量、遮罩控件统一使用底部 LLM 选择框的字号/字重、27px 控件高度、圆角与内边距；菜单文字与行高使用同一套 CSS token，窄窗口不再切换到较大的独立字号。

## 补充：Rhino 插件输入卡片与桌面 Chat 对齐

- 原先输入框上方的模型、图片参数、本地图片和参考控制全部纳入 composer；上方是自适应文本输入，中间是生图模型/比例/清晰度，底栏是本地图片、参考设置、图片开关、聊天模型及发送/停止。
- 附带视口、画布选图、对象遮罩与来源保留在底栏“参考设置”浮层中，参考图数量在图层按钮角标显示；原有消息与 MCP 传输字段不变。
- 采用与桌面 Chat 一致的 8px 选择器字号、27px 高度、5px 圆角与 Lucide 图标。自定义选择器仍通过原 select 的 change 事件工作，保留现有选项与 pending 设置同步机制；菜单挂在文档顶层、以视口定位，避免被输入框或图片区裁切。
- 小窗口约束覆盖长文本、本地图片、多个分件、遮罩和质量参数；参考设置浮层不挤占输入区，分件列表限制视口高度。
- 原生 WebView2 隔离回归：600×820、340×420，明暗模式均通过。检查菜单命中、互斥/关闭、轮询不重建菜单、设置仅派发一次、本地 PNG 上传、发送参数和忙碌/停止状态；不调用真实模型或操作用户 Rhino 文件。
- 本轮 2636 项前端测试、121 项桥接检查、类型检查和前端构建通过。Rhino 8/net7 与 Rhino 9/net8 使用本机实际 SDK 编译通过，并已更新桌面内嵌插件资源；未安装到运行中的 Rhino，未发布新安装包。

# 灵感抽屉 8.0.22

- 优化工作流运行期间的预览、节点尺寸计算和画布缩放，减少重复处理运行数据。
- 优化图片较多的画布，减少拖动、缩放及连接按钮遮挡检查中的重复渲染和节点查询。
- 修复旧工作流因模型名称被错误替换而显示“价格未配置”的问题，保留原节点的模型和清晰度，使用对应的服务端价格估算。
- 修复登录和长任务查询中的凭证缓存问题，改善云端模型获取和生成鉴权稳定性；收到鉴权失败后不会自动重复提交生成。
- 增强托盘和再次启动时的原生窗口恢复，新增有容量上限的本地异常诊断，便于排查界面消失、无响应和渲染进程退出。

本次保留生成并发、网络重试、模型执行映射、请求超时、实际扣费及保存/撤销行为。本地诊断不会自动上传。

# 灵感抽屉 8.0.28

## Chat 与交互预览
- 新增 Canvas 预览窗口：HTML 页面可直接运行和点击交互，支持预览/代码切换、手机宽度、复制与保存 HTML。
- 支持随生成进度刷新及后续修改更新，并可暂停刷新、手动刷新和选择历史版本；切换对话时不显示其它会话的预览。
- 新增结构化 UI 原型生成，可预览页面跳转、弹窗、返回和 Tab 状态切换。
- 新增真正的 .sketch 设计文件导出，可通过 Figma 的文件导入入口使用，不需要 Figma 插件或 MCP。导出保留可编辑文字、图片、图层和静态状态画板；布局按当前尺寸定位，不等同于 Figma 原生 Auto Layout。复杂交互需在 Figma 中重新连接，字体和导入效果请核对；完整交互继续在 Canvas/HTML 中使用。
- HTML 预览与应用原生命令、文件和 Rhino MCP 隔离，不向生成页面开放本地权限。

## 画布与窗口
- 优化大画布缩小到总览时的图块绘制、可见节点管理和缓存调度，减少快速/连续缩放和平移时的卡顿与闪烁。
- 改善预览清晰度与缓存资源复用，减少新增节点及图片时的集中加载停顿。
- 保留不透明 WebView 底色以改善窗口闪烁，并恢复主窗口圆角，随窗口尺寸和 DPI 更新裁切。

## Rhino 与渠道兼容
- 集成此前合并的 Rhino 8/9 插件安装、原生 MCP Chat 联动及文档隔离修复。
- 增强 Rhino 请求参数检查、执行结果识别、聊天图片预览及界面排版，避免把已完成的建模误报成后处理失败。
- 补充 OpenAI Compatible 服务端渠道类型的客户端映射。

此版本保持原应用标识和数据目录，可继续使用已有画布与聊天记录；正式版启用在线更新。Figma 导出已通过公开格式及容器校验，具体导入效果仍需在实际 Figma 文件中确认。

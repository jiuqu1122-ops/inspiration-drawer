# Rhino 插件 0.1.0-beta.36.8

本次更新覆盖 Rhino 8 和 Rhino 9 插件，以及独立建模模块 2026.11.21.3。使用灵感抽屉 8.0.35 的用户可以通过 Rhino 独立更新渠道安装。

- 建模模块在脚本发给 Rhino 前拦截已知的 GH2 同步等待写法，并提示用独立的 GH2 求解工具。
- 原生桥接忙时立即拒绝新请求。文档核对超时后，尚未发出的写操作会被拦住。已发出的写操作如果没有收到明确结果，插件会暂停后续原生写入，提示先检查文档状态。

自动更新后，重启灵感抽屉加载建模模块，重启 Rhino 加载插件。手动安装的 ZIP 对应 Rhino 8 和 Rhino 9，独立建模模块通过更新渠道下载。

验证覆盖 Rhino 8/9 编译、模拟桥接超时和迟到请求、客户端脚本预检。真实 GH2 文档的完整建模任务未重新运行。

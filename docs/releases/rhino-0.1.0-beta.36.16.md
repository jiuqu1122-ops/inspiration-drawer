# Rhino 插件 0.1.0-beta.36.16

配套 Windows 客户端 **9.0.8**。适用于 Rhino 8 和 Rhino 9；安装对应大版本的插件，安装后重启 Rhino。建议先更新客户端，再通过设置中的 Rhino 插件入口更新。独立建模模块更新后请重启客户端。

- 面板输入框显示待发送的本地和画布参考图，支持逐张移除。在小窗口中保留发送按钮。
- 在「参考图与视口设置」选择独立 3DM 草稿，以独立工作文档续改，不修改当前 Rhino 文档；旧桌面端不具备该能力时不会改投原文档。
- 草稿工具新增平滑截面放样、真实孔阵列及材料去除采样。保留独立件时核验对象身份；不会把一个覆盖片当作指定位置的凹槽。
- 对原生 Python 建模失败，尽可能保留真正的脚本行号和异常类型；对已发送但结果未知的操作不盲目重放。
- 从导出的 3DM 独立重读并核对几何，从读回的几何生成四视图。几何有效性不等于制造公差或外观还原度已验收。

独立更新通道：`rhino-updates`（不是桌面安装包的 `latest`）。Rhino 8/9 插件 revision **13**，建模模块 `2026.11.27.1` revision **8**。

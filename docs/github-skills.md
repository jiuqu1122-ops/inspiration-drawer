# GitHub Skills（桌面 Chat）

## 使用

1. 打开 Chat 顶部「智能体」→「从 GitHub 安装」，粘贴公开仓库或技能子目录链接。含斜杠或有歧义的分支请用仓库根链接，单独填写 ref 和技能目录。
2. 点击「检查仓库」，选择含 SKILL.md 的技能，核对来源、目录、固定 commit、文件概况、许可证及兼容性。
3. 点击安装，在原生确认框中确认具体操作。完整包保存在本应用数据目录的 skills 子目录。仅安装不默认在会话选用。
4. 安装后可「本会话使用」；列表中可查看完整文件清单与校验信息、启用／禁用、检查更新、确认更新、回退或卸载。
5. 也可在桌面 Chat 说「帮我找一个适合产品调研的开源技能，安装后用于这次任务」。AI 通过现有搜索寻找候选，检查真实仓库；只有用户原生确认后才安装。

## 边界

- 仅公开 GitHub 技能包，不是任意软件仓库安装器。搜索依赖现有 web_search；不可用时提供粘贴入口，不编造候选。
- scripts、references、assets 等原始文件完整保留；不执行脚本，不安装运行库、MCP、系统软件或插件。
- 预览、确认和下载绑定固定 commit；检查 15 分钟有效，确认一次性消费。更新必须确认，旧版保留，失败不替换旧版。
- 每轮固定技能版本；平时仅提供必要元数据，选用后读取完整 SKILL.md。参考文本明确分页，不提供任意本地路径读取。
- SKILL.md 单轮加载上限 40000 字符、资源读取每页最多 12000 字符、当轮总预算 60000 字符；超限明确报错，不静默截断。
- 单文件 2MiB、完整包 24MiB、512 文件、40 个候选；超限或 GitHub 文件树截断则拒绝。链接消歧最多 12 段。
- 下载串行、无自动重试，连接超时 10 秒、单请求 30 秒、操作总预算 180 秒（在请求边界检查）；可取消。
- 兼容性仅为尽力分析，不是安全审计；缺少脚本/MCP/工具时必须说明，不伪造执行结果。
- GitHub 请求不携带钱包、模型或应用凭据；不要求 Git、Node、Python 或 GitHub Token。
- 仅桌面 Chat 提供新工具；Rhino、HTML 预览和其他窗口不因此获得安装或包内文件读取权限。旧 .md 技能、create_agent 与原有选择数据继续保留。

## 实现

- 原生下载、路径校验、事务与版本存储：src-tauri/src/github_skills.rs。
- 桌面来源校验、取消、进度及原生确认：src-tauri/src/github_skill_commands.rs。
- 复用 chatSkills、ChatAgentPanel、chatContextBuilder、工具定义／路由／执行器和 useChatRuntime；前端只负责 UI 与编排。
- 云端服务端、渠道映射、价格、积分、计费、更新渠道和签名密钥均未改动。

## 验证范围

- 本地 fixture 覆盖根／子目录／多技能、带斜杠 ref、固定快照、事务失败与取消、版本回退、路径越界、特殊文件、限流和资源预算。
- 前端通过真实路由、执行器与 useChatRuntime 模拟搜索→检查→原生确认结果→安装→同任务使用；覆盖伪造授权、拒绝后重试、版本固定、旧数据与隔离。
- 钱包与自定义渠道已核对现有客户端 messages/tools/toolChoice 透传代码，并覆盖本地 IPC 模拟；未调用生产模型，不承诺所有外部模型均支持工具调用。
- 未进行付费生图／视频请求；真实模型的候选质量和工具选择仍受所选渠道支持情况影响。

- 另已使用官方 GitHub API 和固定 commit 内容地址，对 anthropics/skills 的 skills/frontend-design 进行真实下载、SHA256 清单生成和固定版本读取验证；仅使用独立临时目录，结束后清理，不触碰应用数据或执行包内脚本。
